AI-Powered 3D-Printed Prosthetic Hand

I built an AI-powered prosthetic hand using a 3D-printed frame, five servo motors, and an Arduino Uno. The system uses Python, OpenCV, and MediaPipe to track 21 hand landmarks through a webcam and replicate my finger movements in real time. This project explores how computer vision and robotics can be used to develop responsive prosthetic technology.****
